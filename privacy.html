Privacy Policy

Last updated: November 14, 2026

Nemumu Town Tools ("the app") is a private tool used only by the creator of the YouTube channel Nemumu Town. It is not offered to the public.

What the app uses

With the creator's permission, the app uses the YouTube API Services to upload and schedule videos, set thumbnails, captions and playlists, and read statistics for the creator's own channel.

How data is stored and shared

The sign-in token and channel statistics are stored only on the creator's own computer. The app does not sell, share, or transfer this data to anyone, and it does not use it for advertising. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be removed at any time on the Google Account permissions page. The creator can also delete the stored token from their computer.

Contact

Please contact the creator through the Nemumu Town YouTube channel.
